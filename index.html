TikTok Content Posting API

Automate Your TikTok Publishing

Full-stack Flask application for OAuth 2.0 authorization and direct video publishing to TikTok. Connect, upload, and publish — all from one pipeline.

★ View on GitHub → Quick Start
What It Does
🔐

OAuth 2.0 Flow

Secure TikTok authorization with PKCE-style CSRF protection. User grants access, app gets tokens — no passwords stored.

📤

Direct Video Upload

Chunked file upload via TikTok's Content Posting API. Supports videos up to the platform limit with progress tracking.

⚡

Creator Info Query

Fetch allowed privacy levels, comment settings, and duet/stitch options before publishing. No guesswork.

📊

Status Polling

Track publish status in real-time. Know exactly when your video goes live or if something needs attention.

🎨

Built-in Dashboard

Clean, dark-themed UI with all controls in one place. Connect, configure, upload, and monitor — zero context switching.

🧪

Sandbox Ready

Test the full flow in TikTok's sandbox environment before going live. Safe experimentation, no real posts.

The Pipeline

Authorize

User clicks "Connect TikTok" → redirected to TikTok OAuth → grants user.info.basic + video.publish scopes.

Query Creator Info

App calls /creator_info to discover what privacy levels and interaction settings the user allows.

Upload Video

Initialize upload via /video/init/, then push the video file in chunks to TikTok's upload URL.

Confirm Publication

Poll /status/fetch/ until TikTok confirms the video is published and live on the platform.

Quick Start
terminal
# Clone the repo
git clone https://github.com/masterlion-hash/2026Push.git
cd 2026Push

# Install dependencies
pip install -r requirements.txt

# Configure your secrets
cp .env.example .env
# Edit .env → add TIKTOK_CLIENT_SECRET & FLASK_SECRET_KEY

# Run the app
python app.py
# → Open http://localhost:5000
