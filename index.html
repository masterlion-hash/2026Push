Features

Everything You Need to Publish

From authentication to posting — a complete automated pipeline for TikTok content.

🔐

OAuth 2.0 + PKCE

Secure TikTok login with S256 code challenge. No credentials stored — session-only tokens with automatic refresh handling.

📤

Direct Video Upload

Initialize uploads via TikTok's Content Posting API, transfer video files, and publish with custom titles and privacy settings.

📊

Real-Time Status

Poll publish status live — see when your video is processing, published, or if there are errors that need attention.

👤

Creator Info Query

Fetch TikTok creator settings — privacy defaults, duet/stitch permissions, and comment config before uploading.

🎨

Built-in Dashboard

A polished dark-mode dashboard that guides you through every step — connect, configure, upload, and monitor results.

⚡

Single File Deploy

The entire app lives in one Python file. Clone, configure .env, run app.py. No build step, no bundler, no complexity.

Get Started

Up and Running in 60 Seconds

1

Clone the Repository

Get the source code from GitHub and navigate into the project folder.

2

Install Dependencies

Run pip install -r requirements.txt to install Flask, Requests, and python-dotenv.

3

Configure Credentials

Copy .env.example to .env and add your TikTok Client Key and Secret from the Developer Portal.

4

Run the Server

Execute python app.py — dashboard goes live at localhost:5000

5

Connect & Publish

Click "Connect TikTok" on the dashboard, authorize, then upload and publish your first video.

terminal
# Clone git clone https://github.com/masterlion-hash/2026Push.git cd 2026Push # Install pip install -r requirements.txt # Configure cp .env.example .env # → Edit .env with your keys # Launch python app.py # ✓ Dashboard → http://localhost:5000 # ✓ OAuth login → /login # ✓ Upload video → /upload

⚙️ Environment Variables

TIKTOK_CLIENT_KEY
Your app's Client Key from the TikTok Developer Portal
TIKTOK_CLIENT_SECRET
Your app's Client Secret — keep this private
REDIRECT_URI
OAuth callback URL (must match Developer Console config)
FLASK_SECRET_KEY
Random secret key for Flask session encryption
SCOPES
Requested TikTok permissions (user.info.basic, video.publish)
PORT
Server port — defaults to 5000 if not set
