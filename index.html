The Workflow

Step 01

Authorization

Connect your TikTok account securely via OAuth 2.0. Your credentials are never stored — only a session token is held in memory.

Step 02

Creator Info

Fetch your TikTok creator settings to verify privacy defaults, duet settings, and comment configuration before uploading.

Step 03

Upload & Publish

Initialize a video upload to TikTok's Content API, transfer the file, and trigger a direct post with title and privacy settings.

Step 04

Post Status

Poll the TikTok API to check the processing and publication status of your uploaded video after submission.

Pipeline Flow

Connect TikTok

User clicks "Connect TikTok" → redirected to TikTok OAuth

Token Exchange

TikTok returns auth code → App exchanges for access_token

Creator Info

App calls /creator_info to get allowed privacy/comment settings

Init Upload

App calls /video/init → gets upload_url + publish_id

File Transfer

App PUTs video file to upload_url (chunked for large files)

Confirm Publication

App calls /status/fetch with publish_id to confirm live post

Quick Start
terminal
# Clone the repo
git clone https://github.com/masterlion-hash/2026Push.git
cd 2026Push

# Install dependencies
pip install -r requirements.txt

# Configure your secrets
cp .env.example .env
# Edit .env → add TIKTOK_CLIENT_SECRET & FLASK_SECRET_KEY

# Run the app
python app.py
# → Open http://localhost:5000
